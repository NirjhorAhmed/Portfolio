# 🛡️ Sufi Mahbub Ahmed — Personal Portfolio Website

A modern, professional, and futuristic cybersecurity & web application security portfolio website built for **Sufi Mahbub Ahmed**, an undergraduate student at the **Islamic University of Technology (IUT)**.

---

## 🌟 Features & Highlights

- **Aesthetic**: Futuristic cyber-dark theme with deep space navy, glowing cyan borders, and glassmorphism.
- **Dynamic Background**: Lightweight interactive network constellation canvas simulating secure network node topologies.
- **Responsive Architecture**: Fully responsive across mobile devices (375px+), tablets, and widescreen desktop monitors.
- **Accurate & Honest Portfolio**: Accurately reflects student status at IUT without fabricated positions, internships, certifications, or services.
- **Interactive UI**:
  - Scrollspy navigation with sticky frosted navbar and mobile hamburger menu.
  - Interactive Project Roadmap ("Projects Under Active Development").
  - Education Timeline (IUT, Dhaka Commerce College HSC GPA 5.00, MUBC SSC GPA 5.00).
  - One-click copy email button with sleek toast notification.
  - Interactive contact form.
  - Profile card and portrait with glowing cyber-orbit borders.

## 🚀 How to Host on GitHub Pages

1. **Initialize Git & Commit**:
   ```bash
   git init
   git add .
   git commit -m "Initial commit: Sufi Mahbub Ahmed cybersecurity portfolio"
   ```

2. **Link to your GitHub Repository**:
   ```bash
   git branch -M main
   git remote add origin https://github.com/NirjhorAhmed/Portfolio.git
   git push -u origin main
   ```

3. **Enable GitHub Pages**:
   - Go to your repository on GitHub (`https://github.com/NirjhorAhmed/Portfolio`).
   - Click **Settings** > **Pages** (in the left sidebar).
   - Under **Build and deployment** > **Source**, choose **Deploy from a branch**.
   - Select the `main` branch and `/ (root)` folder, then click **Save**.
   - Your live site will be published at `https://nirjhorahmed.github.io/Portfolio/`.
