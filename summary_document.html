2. Step-by-Step Development Lifecycle
1

Requirements Analysis & Compliance Formulation

Analyzed portfolio.txt.txt to extract all structural constraints. Enforced honest student representation: strictly omitting fabricated work experience, fake internships, false certifications, graduation dates, or LinkedIn links, while transforming services into "Areas of Future Focus".

2

Asset Management & Visual Identity Design

Created the directory hierarchy (assets/images/, css/, js/, .github/workflows/). Integrated the user-uploaded portrait (profile.jpg) and styled it with a high-tech glowing orbit frame, cyber brackets, and floating status chips.

3

Semantic HTML5 Front-End Construction

Developed index.html with all core sections: Sticky Navigation, Hero section, About Me, Education Timeline (IUT, Dhaka Commerce College HSC 5.00, MUBC SSC 5.00), Categorized Technical Skills, Projects & Learning Roadmap, Career Journey, Areas of Future Focus, Gaming Interests, and Contact form with Email Copy button.

4

Cyber-Dark Styling & Animations Engine

Crafted css/style.css and css/animations.css using modern CSS variables, glassmorphism (backdrop-filter), cyber-neon cyan highlights (#00f0ff), responsive flex/grid layouts, glowing borders, and scroll-reveal triggers.

5

Interactive 3D Cyberspace "Entering The System" Engine

Engineered a custom 60 FPS HTML5 Canvas engine in js/particles.js. Implemented a 3D perspective grid highway (floor & ceiling), passing security firewall gates (SYS_AUTH, FIREWALL // BYPASS OK, MAINFRAME // LEVEL 01), peripheral matrix code drops, interactive mouse flight steering, and scroll speed acceleration.

6

Git Version Control & GitHub Pages CI/CD Deployment

Configured git tracking, added .nojekyll for raw static file serving, created automated GitHub Actions deployment workflow (.github/workflows/static.yml), and pushed all assets to the public GitHub repository for live hosting.
